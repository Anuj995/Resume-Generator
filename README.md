# Resume Generator

A simple and beginner-friendly Resume Generator web application built for an internship project.

## 🚀 Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Local React state & LocalStorage

## 📌 Features
- **Information Input:** Provide plain text career details, projects, education, and achievements.
- **Job Role Selection:** Choose from 8 target job roles (Frontend, Backend, Full Stack, Data Analyst, UI/UX Designer, etc.).
- **Organized Information:** Categorizes raw details into structured sections and highlights role-relevant skills.
- **Resume Editor:** Interactive 2-column layout with editing controls and dynamic live preview.
- **Resume Preview & PDF Download:** Clean professional resume layout with printable/PDF export capabilities.

## 🛠️ Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
